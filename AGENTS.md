# Repository instructions

## Mandatory language policy

Use English for all development work and all communication with the user, including progress updates and final explanations. This policy applies to every future development phase.

- Write source code identifiers, inline comments, docstrings, and type descriptions in English.
- Write UI text, API responses, error messages, test names, assertions, and fixtures in English.
- Write README content, technical documentation, architecture and verification reports, development summaries, commit messages, and pull request descriptions in English.
- When editing existing files, translate any Turkish prose into professional technical English while preserving functionality. Keep unrelated code unchanged.
- Verify the relevant files before claiming language compliance, and run relevant tests after changes.

Preserve legal attribution and proper names. English-only does not require removing valid Unicode punctuation or UI symbols.
